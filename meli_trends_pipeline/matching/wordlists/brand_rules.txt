# Brand rules: curated ways of naming a brand that the master list (brands.xlsx) misses
# or cannot use safely. One rule per line:
#
#     alias | Brand as shown in dashboards | optional categories, separated by ";"
#
# - alias: words as typed in searches (normalized like keywords: lowercase, no accents).
#   "#" stands for one model code, i.e. a token with a digit: "galaxy #" matches
#   "galaxy s24" and "galaxy a55", not "galaxy" alone.
# - categories: homologated Mercado Libre categories (mercado_libre_subcat.xlsx). The
#   rule only fires for keywords of those categories: "wilson" is the brand in
#   "Deportes y Fitness" (raqueta wilson), not in "Arte, Librería y Mercería".
# - A rule replaces the master-list entry with the same alias, so it also fixes the
#   display name ("dji" -> "DJI") and lifts the ambiguity of "wilson" inside its categories.
#
# Every rule was checked against real trend keywords; keep it that way: an alias that is
# also an everyday word needs categories.
